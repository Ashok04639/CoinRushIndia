# Coin Rush India — Mobile Cloud Build

This project includes a GitHub Actions workflow at `.github/workflows/build-apk.yml`.

On GitHub: open **Actions → Build Coin Rush India APK → Run workflow**.
When the workflow finishes, open the run and download the artifact **CoinRushIndia-debug-apk**.

The debug build uses Google's test ad units by default. Do not click test ads. Before publishing, configure production/release signing and switch ad configuration deliberately.
